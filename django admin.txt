Common Methods in ModelAdmin
get_queryset(self, request): Returns the queryset of objects to be displayed in the admin list view. It can be overridden to customize how objects are fetched or filtered.​

get_list_display(self, request): Allows dynamic modification of the list of fields shown in the admin list view.​

get_search_fields(self, request): Used to define search fields dynamically based on the request.​

get_list_filter(self, request): Specifies filters for the right sidebar on the change list page.​

get_urls(self): Used to add custom views to the admin interface for your model.​

get_actions(self, request): Returns the actions available for the current request, allowing actions to be conditionally enabled/disabled per user or request.​

save_model(self, request, obj, form, change): Called when an object is created or updated via the admin. Used to customize how the object is saved.​

delete_model(self, request, obj): Called when an object is deleted in the admin. Used for custom deletion logic.​

has_add_permission(self, request): Controls whether the "add" button is visible to the requesting user.​

has_change_permission(self, request, obj=None): Determines if a user can change a specific object.​

has_delete_permission(self, request, obj=None): Determines if a user can delete a specific object.​

log_addition(self, request, obj, message), log_change(self, request, obj, message), log_deletion(self, request, obj, message): Used to log changing events in the admin—helpful for audit trails.​

formfield_for_dbfield(self, db_field, request, **kwargs): Allows customization of how each model field is rendered in the admin forms.​
