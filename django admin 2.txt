What fields work well in list_filter?
Field                         Type	Behavior
CharField with choices	         Shows dropdown choices ✅
BooleanField	                  Shows Yes / No filter ✅
DateField / DateTimeField	       Shows date range filters ✅
ForeignKey	                       Shows select list of related objects ✅
IntegerField	⚠                  Shows choices only if small set (e.g., pages won’t auto filter well)

What raw_id_fields Does

Normally, if a model has a ForeignKey, Django shows a dropdown:

Author:  [ dropdown containing 5000 names ]  ❌ slow + heavy


If your related table is large, this dropdown becomes:

slow to load

hard to search

raw_id_fields changes it to:

Author: [   24   ]  🔍
Where:

24 is the ID of the selected Author

Clicking the 🔍 lookup icon opens a mini search window

both raw_id_fields and autocomplete_fields only work when the field is a ForeignKey or ManyToManyField.

They do NOT work for normal fields (CharField, IntegerField, etc.).
